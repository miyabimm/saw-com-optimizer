## Binding boundaries

Delete the historical schema-v1–v4 `python -m sawopt export-review` capability, its old GitHub exporter, and only its exclusively old-format adapters/specs/tests. Keep R5 `sawopt.raw_run/1` and `sawopt.review/1`, the synthetic CLI's automatic R5 package export, scientific calculations and saved-evidence regressions, historical artifacts, and independently used run-status/publication/storage/checkpoint safety. This is a capability retirement, not migration or removal of historical evidence.

No COM/FE/optimizer study, WSL qualification, production export, historical raw/checkpoint access, run/PID/worker inspection, evidence rewrite, or R7/Q1 transition is authorized or performed.

## Test disposition

- Remove `tests/unit/reporting/test_github_review_export.py` as old-schema-only coverage. Its CLI dispatch, legacy output layout/manifest, copying, redaction, traversal, incomplete-matrix, hard-size, idempotence and old run-status-export assertions test a capability that is intentionally deleted; they do not test R5. Existing R5 unit/integration tests remain the authoritative new-schema coverage.
- Remove `tests/unit/test_main_cli.py`'s six legacy-command parser-rejection cases because the entire module dispatcher is gone; the new static absence regression directly pins that stronger boundary without imports or side effects. No R5 or scientific behavior is dropped.
- In `tests/unit/studies/test_hybrid_stage4c.py`, remove only `_synthetic_review_run`, `test_stage4c_dedicated_review_spec_and_export`, and `test_stage4c_exporter_fails_closed_on_contract_mismatch`; retain frozen config, scientific report/classification, manifest, candidate-ranking, and historical goldens. Update the fingerprint assertion to pin the exporter-free reporting dependency set without changing computation dependencies.
- Relocate the `mark_review_published` pushed-package/hash/active-run-release check from the combined legacy-export test into an orchestration-focused test with a synthetic temporary Git/package fixture. Keep CLI publication, status rendering, administrative closeout, PID/lock/worktree/storage and checkpoint safety tests.
- Add a static negative regression for absent `sawopt.__main__` and `reporting.github_review`, while asserting the independent `sawopt.cli` entry and R5 modules remain present. It must not import or execute COM, optimizer, CLI dispatch, I/O lifecycle, or run code.
- Preserve `tests/unit/reporting/test_experiment_review.py`, `tests/unit/io/test_experiment_store.py`, synthetic CLI integration/recovery, Q1-A 92/92 public and leaf goldens, both import guards, Stage 5A-1 audits, R2–R4 numerical/regression coverage, and independent Stage 4B/C report/scientific tests.
