# Future experiment design — not an execution guide

Historical Stage 3/4 study executors, audits, old study configuration loading,
and saved-run report/ZIP pipelines have been removed under Issue #129. The
current `sawopt` CLI is synthetic/injected-only; R5 storage and review export
are future-only and do not provide a scientific optimizer runner. Do not
recreate a removed historical entrypoint or interpret this page as experiment
authorization.

Any future experiment design must follow the current roadmap and obtain the
separate owner authorization described in
[`../experiments.md`](../experiments.md). Keep COM equations, units, modeled
constraints, ranking, FE accounting, RNG, and checkpoint state unchanged unless
a material scientific-contract change is explicitly approved. Historical
reports and source identities remain records; finite search is best-found, not
proof of a global optimum.
