# Historical asynchronous orchestration — retired

The former detached scientific-run launcher, worker, queue/callback, recovery,
status, and publication lifecycle has been retired. The remaining synthetic
task Worker/SQLite ledger is a bounded software-only fixture path; it is not a
scientific optimizer runner or continuation service. No old launch/resume or
queue procedure is supported or authorized.

Use the current synthetic CLI only for its documented injected/software tasks.
For scientific experiment authorization and R5 storage limits, see
[`../experiments.md`](../experiments.md). The project-local worktree-safety
utility was retired under Issue #143; future worktree operations are governed
by the [worktree operations policy](worktree_safety.md).
